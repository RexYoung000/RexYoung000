## Featured / 重点项目

### [Meaning Check](https://github.com/RexYoung000/Meaning_Check)

**Understand what a post means, how it sounds, and why.**

一个帮助读懂公开帖子与回复的开源浏览器插件：点击「帮我意图识别」，在原文下方查看主解读、语气和原文依据。

- **Read in place / 原位阅读** — separate cards under each post, with multiple tasks, loading feedback and per-card cancellation.
- **Bring your own API / 自带模型 API** — nine provider presets and custom compatible endpoints; keys stay in the local extension.
- **Choose your language / 按自己的语言理解** — Chinese / English interface, independent analysis language, X / Reddit and selected text on allowed sites.
